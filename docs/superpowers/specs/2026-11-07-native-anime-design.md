# Аниме и YummyAnime в обычном интерфейсе Lampa

## Сценарий

Пользователь открывает существующую вкладку «Аниме», выбирает поиск, вводит название и получает результаты в привычном интерфейсе Lampa. Карточка тайтла остаётся стандартной. В разделе «Онлайн» доступен источник YummyAnime; выбор озвучки и серии ведёт в установленный Just Player без открытия главной страницы или отдельной карточки YummyAnime. «Назад» возвращает к предыдущему списку с сохранённым фокусом.

## Подходы

1. Источник YummyAnime внутри «Онлайн» и поиск из вкладки «Аниме». Пользователь выбрал этот вариант: он сохраняет привычную навигацию.
2. Отдельная кнопка YummyAnime в карточке. Требует дополнительного пути вне списка источников; пользователь предпочёл первый вариант.
3. Переработка отдельного интерфейса YummyAnime. Не решает просьбу работать внутри Lampa.

## Реализация и ограничения

Переиспользовать API поиска, сопоставление тайтлов и проигрывание из текущего плагина. Существующая регистрация `Lampa.Online.register` требует проверки совместимости с установленным Online Mod: нынешняя заготовка открывает меню плагина и возвращает пустой список. Реальная интеграция должна показывать результаты выбранного источника в стандартном экране «Онлайн».

Поиск в «Аниме» должен быть доступен с пульта и искать аниме по названию, а не только фильтровать уже загруженные карточки. Результаты открывают обычные карточки Lampa. Если каталог YummyAnime содержит тайтл без соответствия в TMDB, показать понятное сообщение либо стандартный список воспроизведения; не перебрасывать пользователя молча в отдельную карточку YummyAnime. Конкретный совместимый способ выбирается после проверки API установленной Lampa.

Сохранить настройки резолвера Alloha на VPS, плеер, выбранные озвучки и историю. Проверить поиск, выбор YummyAnime в «Онлайн», запуск серии Alloha, возврат и повторное открытие на GX1. Не обещать работоспособность остальных провайдеров без отдельной проверки.
